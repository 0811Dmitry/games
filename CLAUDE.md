# Мастерская игр

## Что это

Личный проект: папа и сын (8 лет) вместе придумывают и делают маленькие браузерные игры —
это регулярное совместное занятие, не разовая задача. Сын надиктовывает/формулирует идею,
Claude делает игру, оба тестируют и играют вместе, и когда результат нравится — игра
публикуется на общий сайт, чтобы в неё можно было играть с телефона и скидывать ссылку
одноклассникам.

Первая игра — **ПЕРДОБЕГ**, курьер на самокате развозит заказы по городу (машины, тропинки,
рампа для трюков, горох для ускорения). Смотри `games/perdobeg/index.html` как референс
стиля и уровня сложности.

## Структура репозитория

```
index.html              — каталог всех игр (витрина, "картриджи" со ссылками)
games/
  perdobeg/
    index.html           — сама игра, полностью самодостаточный файл
  <slug>/
    index.html            — так же будет оформляться каждая следующая игра
```

Каждая игра — отдельная папка `games/<slug>/` с `index.html` внутри. Ссылка на игру в
каталоге — относительный путь `games/<slug>/`.

## Как публиковать (важно!)

1. Делаем и тестируем игру локально как обычно — просто открываем `index.html` в браузере,
   ничего никуда не уходит.
2. Когда всё устраивает и хочется опубликовать — коммитим изменения.
3. **Перед `git push` всегда явно спрашивай подтверждение у пользователя** — это публичный
   репозиторий, пуш должен быть осознанным действием, а не автоматическим следствием коммита.
4. После пуша сайт обновляется сам, отдельного деплоя делать не нужно.

## Как добавить новую игру

1. Создать `games/<slug>/index.html` (slug — короткое английское имя игры).
2. Добавить в корневой `index.html` новую карточку-"картридж" в блок `.games` (скопировать
   разметку существующей карточки ПЕРДОБЕГ, поменять заголовок/описание/теги/ссылку). Плейсхолдер
   "Следующая игра появится здесь" остаётся последним элементом.
3. Обновить счётчик `.count` ("В коллекции: N игр") в шапке каталога.
4. Закоммитить и запушить (с подтверждением, см. выше).

## Технические конвенции для игр

- **Один файл на игру.** Каждая игра — самодостаточный `index.html` (HTML+CSS+JS инлайном),
  без внешних зависимостей, CDN, npm, сборки. Это не жёсткое ограничение технологии (обычный
  git-репозиторий, можно подключать что угодно), а сознательный выбор ради простоты: файл
  можно открыть двойным кликом, легко читать и редактировать вместе с ребёнком, ничего не
  ломается при деплое.
- **Мобильный экран — не десктоп.** Сын играет в основном с телефона. Обязательно: адаптивный
  канвас на весь экран (без леттербоксинга), сенсорное управление (джойстик/кнопки через
  Pointer Events), проверка на реальных пропорциях экрана. Ориентируйся на то, как это сделано
  в `games/perdobeg/index.html` (функция `resizeCanvas`, `#joystick`, media-query
  `(hover: none) and (pointer: coarse)`).
- **Звук** — простые процедурные бипы через Web Audio API (осцилляторы), без аудиофайлов —
  так проще и не раздувает репозиторий.
- **Язык интерфейса** — русский.
- **Возрастной ориентир** — 8 лет: простое управление, дружелюбный юмор, быстрый вход в игру
  (не больше пары абзацев правил на стартовом экране), сессия на 1-2 часа разработки с
  видимым результатом.
- Визуальный стиль у каждой игры может быть свой — не обязательно повторять пиксельный
  стиль ПЕРДОБЕГ, если новая идея просит другую эстетику.
